## Included capabilities

- The Windows Agent/control plane runs in Session 0 and uses authenticated
  local named-pipe IPC to a persistent interactive Runtime Worker. The Worker
  owns the serialized MT5 API connection and terminal in its runtime session.
- The Agent remains available with degraded health when the Worker is absent.
- Safe production reads include symbols total, terminal version, and account
  information. Account values are withheld from logs and acceptance evidence.
- Agent packaging excludes MetaTrader5, NumPy, the legacy direct MT5 adapter,
  the interactive Worker module, and `terminal_inspection`.
- No trading capability was added by this release.
