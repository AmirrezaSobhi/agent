# MT5Agent v0.1.5 — Windows Desktop Integration

**INTERNAL / PRE-PRODUCTION**

**UNSIGNED — NOT APPROVED FOR PUBLIC DISTRIBUTION**

This version integrates the C# WPF/.NET Framework 4.8 Desktop with the Python
Agent and a separately provisioned interactive MT5 Worker. The unified Inno
Setup installs Desktop, Service, Agent and Worker components. Service/Agent
run as LocalSystem in Session 0; the standard RuntimePrincipal and external
MT5 terminal remain in the interactive session. Management and Runtime pipes
retain separate SID/DACL and per-operation authorization boundaries.

The product, Core/CLI, Installer and bundled Worker version are `0.1.5`;
Desktop/Service file metadata is `0.1.5.0`. Pipe protocols remain version 1.
The Installer manifest and release-provenance asset identify exact source,
pipeline, build/verify jobs and component hashes. No real trade is part of
release validation. Server Decides → Agent Validates & Executes → Structured Results.

## Installation and upgrade

Requires Windows x64, .NET Framework 4.8, elevated installation, an existing
MT5 installation and a separately configured standard interactive RuntimeUser.
Setup does not create accounts, store passwords, enable Autologon or change
MT5 accounts/profiles. Close the Desktop including its tray instance before
upgrading. Verify Installer/sidecar/manifest hashes, record the initial state,
use an absolute installer/log path, and retain PID/exit/timestamps and fresh
post-install health. Preserve existing Worker configuration and MT5 data.
See the [Installer runbook](../../deployment/installer/README.md).

the Release's internal Generic Package assets. The release-provenance,
windows-acceptance and release-authorization assets record exact approved
bytes, operational results and independent Owner approval. Generic Package
files are read back and hashed before Release creation; conflicting existing
files/releases are not overwritten. Internal tags do not authorize GitHub
publication; source mirroring remains governed by the existing repository policy.
