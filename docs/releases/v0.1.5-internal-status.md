# MT5Agent v0.1.5 internal development status

**Status:** Implementation in progress pending the final Windows GitLab
pipeline. This is an internal development branch, not a public release.

## Implemented in source

- Desktop-local Service Control Manager status, Start, Stop and Restart for
  the fixed `MT5Agent` service name. SCM checks the current user's query/start/
  stop rights. Stop and Restart require confirmation; duplicate actions are
  suppressed, waits are bounded/cancellable, results are shown and read back.
- Per-user local operation audit entries contain UTC time, operation and
  sanitized result/state only. No SID, account, terminal path or credentials
  are written.
- Management status includes actual Agent and protocol versions, Worker
  protocol/session metadata, and last successful MT5 operation only when the
  authenticated adapter exposed those fields. Service remains `UNKNOWN` in
  the Agent pipe and comes from SCM independently.
- Logs include optional 30-second auto-refresh with overlap prevention and a
  100-event UI bound. Diagnostics can copy an explicit safe field allowlist.
- CI package version is `MT5Agent-Desktop-v0.1.5-windows-x64.zip`; build job
  `desktop:build-package` is the downloadable artifact source and the verifier
  consumes the same archive.

## Limits and deferred validation

The repository does not install or configure the Windows Service. SCM controls
apply only when a Service named exactly `MT5Agent` is already provisioned and
the current Windows account has the matching SCM rights. The packaged Desktop
does not install that Service or change its ACL. Windows 11 and Windows Server
2022/2025 validation, RDP multi-session, extended DPI, screen-reader, soak and
commercial signing remain `DEFERRED — PRODUCT OWNER VALIDATION` or deferred
release work.
