# MT5Agent v0.1.5 internal development status

**Status: PARTIAL — Windows 10 installation, Service/Agent control plane and WPF smoke passed; interactive Worker/MT5 runtime remains unconfigured.** This is an internal development candidate, not a public release.

## Candidate and CI

- Feature branch: `feat/v0.1.5-desktop-integration`.
- Pipeline #82, commit `bb7928643ed5f45ecd70afbad032d88ef833a034`: all 14 jobs passed. Installer build #834 and exact-artifact verification #835 passed.
- Installer: `MT5Agent-Setup-v0.1.5-windows-x64.exe`, 22,459,348 bytes, SHA-256 `5578546e223cec3d23f8d25e78a6e0d1d62af7c0f04db13b26255b9184b39404`. Manifest and SHA sidecar matched on Ubuntu and Windows.
- The verified artifact is unsigned and internal-only. Pipeline success does not prove installation; see the Windows evidence report for real VM results.

## Implemented and verified

- Packaged Windows Service disables development HTTP and continues to expose the authorized read-only Management Named Pipe.
- The Service creates a per-Agent shutdown event and signals it during stop. Windows test coverage verifies the shutdown path, and the installed Pipeline #82 Service stopped the Agent gracefully in 1.891 seconds.
- SCM Recovery read-back accepts `TRUE` and `1`, rejects `FALSE`, invalid and incomplete values. Real Windows 10 SCM read-back returned `TRUE`; recovery actions are bounded to 5 and 15 seconds.
- Pipeline #82 regression jobs passed: Linux/Windows Python suites, WPF/Management IPC tests, Service lifecycle tests (12 passed), package/installer build and exact artifact verification.
- Real Windows 10 install completed once with Installer PID 4912 and Exit Code 0. Service and Agent started in Session 0. Authorized Management requests succeeded, LocalSystem was rejected, unsupported privileged operation was rejected, and no loopback HTTP listener remained.
- Installed WPF v0.1.5.0 launched in interactive Session 1, opened five implemented views, returned live degraded runtime health, and exited while the Service stayed running.

## Remaining limits

- **Worker/MT5 NOT CONFIGURED:** the package contains the Worker, but no runtime principal, machine runtime configuration or interactive Worker task exists on the installation VM. The existing MT5 installation remains intact and no MT5 terminal was running. Worker-to-MT5 initialization, safe reads, reconnection, RDP/logoff and boot behavior remain unverified.
- Service stability was observed for 987 seconds across 32 samples with no Service restart or Agent PID-set change. One controlled Agent termination was automatically recovered in 12.61 seconds. Repeated crashes, reboot and RDP/logoff were not exercised in this test cycle.
- WPF smoke used 96 DPI. High-DPI, screen-reader and tray-menu interaction remain untested.
- Windows 11 and Windows Server 2022/2025 remain untested. No release tag, merge to staging/main, public release, snapshot operation or real trade was performed.
